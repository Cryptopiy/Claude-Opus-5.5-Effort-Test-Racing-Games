## Русский

### Тест уровней effort Claude Opus 5.5 — 6 гонок с открытым миром (Low → Ultracode), Godot

Из ролика **Opus 5.5 Effort Test**: один и тот же промпт (гонка с открытым миром в духе Forza Horizon) Claude Opus 5.5 выполнял на шести уровнях рассуждения — Low, Medium, High, XHigh, Max и Ultracode. Все машины и окружение — из Blender через Blender MCP. Версия Ultracode включает доработки после ролика (пешеходы, текстуры земли, орбитальная камера).

## English

### Claude Opus 5.5 effort test — 6 open-world racing games (Low → Ultracode), Godot

From the **Opus 5.5 Effort Test** video: Claude Opus 5.5 ran the same prompt (a Forza Horizon-style open-world racer) at six effort levels — Low, Medium, High, XHigh, Max and Ultracode. All cars and scenery come from Blender via Blender MCP. The Ultracode version includes post-video improvements (pedestrians, terrain textures, an orbit camera).
